# Customer Support Workflow & Scripts

## Support rules

- Verify the customer before discussing private order details.
- Use the order number and the checkout mobile number for website-order verification.
- Never request passwords, payment PINs, OTPs or full card credentials.
- Do not expose internal CRM notes, batch IDs, unit costs, supplier details, staff information or finance records.
- Do not promise a refund until Finance has approved the settlement.
- Do not promise a returned product will be restocked.
- Avoid inventing delivery dates. Use the actual CRM/courier state.
- Customer-facing messages should be clear, short and factual.

## Order-status enquiry

Use the public Track Order flow first.

Suggested reply:

> Your latest Aloyri order status is **[status]**. Your order reference is **[order number]**. If a courier reference is available, you can use it for the latest delivery information.

If no courier reference exists:

> Your order is still within Aloyri's fulfilment process. We’ll update the order status when it reaches the next confirmed step.

Do not say “it will arrive today/tomorrow” unless there is a reliable operational basis for that promise.

## Order received

> We’ve received your Aloyri order **[order number]**. We’ll process it through confirmation, packing and delivery. You can check the latest status from the Track Order page using the same mobile number used at checkout.

## Customer wants to cancel

Before shipment:

> We’ve received your cancellation request. We’ll review the current fulfilment status and confirm whether the order can still be cancelled.

After shipment:

> The parcel has already entered delivery. We’ll review the available return/cancellation options based on its current delivery status.

Do not promise cancellation if the parcel is already outside Aloyri's control.

## Wrong product delivered

> We’re sorry the delivered item does not match the order. Please keep the product and packaging available and submit a return review using your order number and checkout mobile number. If useful, keep clear photos of the received item and packaging. Please do not send the item back until Aloyri confirms the next step.

## Damaged product

> We’ve received your report about a damaged item. Please keep the product and packaging, and keep clear photos if available. Submit a return review so the order and affected item can be verified. Aloyri will confirm the next step after review.

Do not tell the customer that damaged stock will be refunded or replaced automatically.

## Missing item

> We’ll review the order and the missing item. Please submit a return/support review using your website order number and checkout mobile number, and select the affected product. Aloyri will confirm the resolution after checking the order.

## Return request received

> Your return request for **[order number]** has been received for review. This does not automatically create a refund or restock the product. Please wait for Aloyri’s return instructions before sending anything back.

## Return request approved

> Aloyri has approved the request for the next return-review step. Please follow the return instructions provided by the team. The final refund, replacement, store-credit or no-refund outcome is confirmed separately after the required review.

## Refund approved

Only send this after Finance records/approves the settlement:

> Your refund for **[order number]** has been approved for **৳[amount]**. The team will process it using the confirmed refund method. Keep this order reference until the refund is completed.

## No-refund outcome

> Aloyri has completed the return review for **[order number]**. Based on the review, no customer refund is due for this return. If you need clarification, reply with the order reference and we can explain the recorded outcome.

## Store credit / exchange

> Aloyri has approved **[store credit / exchange]** for **[order number]**. The team will provide the next order/credit instructions. This is separate from cash refund processing.

## Out-of-stock question

> The website shows the latest customer-safe availability from Aloyri’s inventory system. If an item is unavailable, it cannot be ordered until stock becomes available again.

Do not promise a restock date unless Purchasing/Inventory has confirmed one.

## Support handoff

Escalate to:

- **Sales/Admin:** order/customer fulfilment question.
- **Inventory/Admin:** damaged/returned physical product, stock or batch issue.
- **Finance/Admin:** collection, refund, store credit or settlement question.
- **Owner/Admin:** policy exception, sensitive complaint, data/security issue or operational override.
